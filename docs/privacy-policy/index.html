2. Personal & Financial Data Processed

  • Account Profile: Display name, email address, optional phone/birthdate if added by you, and chosen avatar.
  • User Ledger Records: Expenses, income, categories, budgets, and personal lending/borrowing agreements and repayments synced for multi-device continuity.
  • Consent & Age Verification: Age bracket indicator (18 or older vs Under 18), parent/guardian email & verification token for minors, versioned Terms/Privacy acceptance timestamps, SMS consent timestamps, and privacy request logs.
  • Optional On-Device SMS Alerts: When explicitly enabled with Android READ_SMS / RECEIVE_SMS permissions, only financial alerts from recognized Kenyan financial sender IDs (M-PESA, Fuliza, PesaLink, Kenyan banks) are parsed locally inside your phone.

3. On-Device Processing vs. Cloud Providers

  • On-Device Only: Raw SMS text messages, temporary Android SharedPreferences queues (xpense_sms_capture), SMS deduplication fingerprints, and local offline AsyncStorage caches remain on your device. Raw SMS inbox text is NOT uploaded to cloud databases or third-party AI/ad networks.
  • Cloud Providers: Synced user ledger records, consent logs, and authentication credentials are stored in Supabase (PostgreSQL + Supabase Auth, TLS + Row-Level Security). Optional Google Sign-In uses Google OAuth. WebView UI styling fetches Tailwind/Material stylesheets from public CDNs while online.

4. Children’s Privacy (Under 18 in Kenya)

Under the Kenya Data Protection Act, 2019 (Section 33), individuals under 18 require parent/guardian consent. Minor accounts start in a restricted state with automated SMS detection disabled until a parent or guardian verifies consent via our Parental Consent page.
